## CLI authority, execution and recovery

`pilot-admit --inputs PRODUCER --calibration CALIBRATION --output FRESH` performs
only admission preparation and current qualification. Default output is DRAFT.
`--approve --reviewed-by NAME` explicitly approves the frozen v3 design and the
exact compatible data/source/image/resource/cost values produced by those checks;
it publishes ADMITTED only if every gate passes. It never launches learning.
Blank review, missing private inputs, unknown schema, changed source, incomplete
cost/clock, changed environment or failed current gates cannot publish admission.
Failure still exports one bounded evidence bundle. Admission cap43200s includes
current builds/tests/import/export; no training or calibration stage is registered.
This separately charged preparation precedes the warm study's original48h clock.

`pipeline-pilot-cost/v2` nests the original candidate without rewriting observations,
recomputes it exactly, binds current source/profile/compatibility and reserves the
new evaluation envelope. A candidate or legacy cost alone cannot grant authority.
`pipeline-study-authority/v2` approves the exact decision payload.
`pipeline-pilot-qualification/v2` binds current receipt identities and hashed
references, both current image digests, work/resources/CPU/engine and compatibility.
Parsing checks public authority, receipt bytes/artifacts/prerequisites, image and
cost bindings before resolving private prepared data. Version isolation is strict.

Run an admitted decision via the existing main CLI `validate --suite pipeline
--phase 6 --study-manifest PATH --output FRESH`. It rechecks source/resources,
images and original filesystem scope, then uses the existing worker and complete
CheckpointStore. The learner receives visible examples/recipe and public source
compatibility proof; generator receives only visible prompts and its own complete
checkpoint. Scorer remains CPU-only with selections/truth and no checkpoints.
The new worker profile/purpose binds resume state, denying legacy/diagnostic state.
Full-clock cost completeness is reported separately from scientific coverage.

Recovery uses the identical admitted decision and a fresh output directory on the
same boot within the original lifetime; it never repeats charged slots. The
existing atomic ledger/controller lock,16invocation limit, full-state CPU audit,
zero-active native boundary, fatal/late/orphan refusal,16GiB transient/32GiB durable,
5GiB free floor and512MiB evidence/archive bounds apply. Keep all original full

No new automatic study, curriculum, replay, default adoption or final exposure follows.
