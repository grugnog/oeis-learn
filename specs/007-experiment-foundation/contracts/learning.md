# Learning, search and richer WAT contract

Prepared against the current source and attached independent review, 2026-09-16. Normative for FR-025–030 and FR-035. This specifies implementation targets, not measured results. All experiment budget/threshold numbers below are planning defaults to freeze in a manifest, not user-confirmed performance predictions. Only native LODA, its language comparison and any later transcoder belong outside 007. KV cache is included: it addresses the observed dominant generation phase and can be qualified without a new training arm.

## 1. Priority and dependency order

1. P0: fix sampling/scoring policy mathematics, module-mode leakage, archive admission, curriculum observations and disconnected replay; keep SFT as the first qualified objective while implementing the other modes in the same feature.
2. P1: typed logical IR and complete literal/local codec, exact input information, family-isolated generic data, cached/batched decoding and bounded search/self-training.
3. P1: explicit streaming/array execution profiles, wide primitive coverage, cost-aware scheduling and measured hardware configuration.
4. P2: a bounded development decision pilot compares one evidence-selected challenger to its baseline. Position, capacity, learned abstraction and learned search improvements remain conditional work inside 007; they need an explicit proceed/no-benefit/inconclusive result, not a deferred-spec placeholder or an unconditional sweep.

Known defects must receive executable regressions and repairs, not simply exclusion of the legacy subsystem. Old entry points should call the corrected services or reject unsupported legacy semantics explicitly; archive inspection can preserve old artifacts without admitting them to strict learning.

## 2. RL policy and replay repair

Existing implementation targets: `src/oeis_learn/rl/{trainer,egca_grpo,reward,telemetry,sft_trainer}.py`, `src/oeis_learn/decoder/sampler.py`, `src/oeis_learn/sandbox/tracer.py`; focused existing tests include `test_egca_training_step.py`, `test_kl_regularization.py`, `test_partitioned_entropy.py`, `test_egca_credit_assignment.py`.

Add a versioned rollout record: prompt-content hash, full behavior encoder/decoder checkpoint hash, sampled token IDs, legal-support masks (or deterministic mask replay plus grammar hash), per-step temperatures, behavior action log-probabilities, EOS position, forced-action mask, RNG identity, runtime evidence and reward components. Cache/encode the visible prompt once against an immutable inference snapshot. Do not recompute old probabilities from current detached logits. Training defaults to top_p=1.0, fixed temperature 0.8, no top-k and dropout disabled consistently for rollout and policy scoring; gradients remain enabled in `.eval()` mode. Restore every module's prior training flag on all sampling exits, including exceptions. SFT may use its declared dropout separately. If an API requests unsupported truncation with policy gradients, reject the configuration rather than silently mis-score it.

Policy scorer applies the exact grammar support and declared temperature to current logits. Forced wrapper/completion tokens, PAD and unobserved trailing tokens contribute no policy objective, KL or entropy. EOS is included when sampled. Dead-end grammar/truncated incomplete programs are explicit rollout failures; repair candidates are separate search results and, if verified, SFT examples, not on-policy trajectories. Compute masked entropy with safe zero-probability handling (avoid `0 * -inf` NaNs); normalize by log(number of legal choices) only where >1.

Implement named objectives: SFT, fresh-rollout REINFORCE, corrected GRPO. GRPO uses stored behavior probabilities and symmetric clip epsilon=0.2 by default; per-prompt advantages use real sampled rewards only and become zero when group variance is zero. Do not inject synthetic positive rewards from elite demonstrations. Use mean token loss per trajectory, then mean over actual trajectories, and record the normalization. Reference regularization, if enabled, freezes both encoder and decoder with immutable identity; exact full-vocabulary masked categorical KL is the small-vocabulary debugging oracle. A sampled KL estimator must identify which sampling distribution its expectation uses and cannot be called unbiased after stale-rollout drift without correction. Default KL coefficient is 0.01 and entropy coefficient 0.0, explicitly frozen. These are planning defaults, not experimentally optimal values.

Proxy text spans must not masquerade as execution-guided causal credit. Replace the tracer contract with a real instruction/basic-block ID map through lowering and runtime/reference traces, or return `unsupported` for unsupported trace modes. Full-trajectory reward is the default. Trace-informed shaping is an optional in-007 pilot challenger only after trace-to-source correctness tests; masking by guessed textual spans is removed.

Acceptance: enumerate a tiny two-step legal-action policy and compare every sampler/scorer probability and analytical/finite-difference gradient under temperature, masks, forced tokens and EOS. Perturb current weights after rollout and demonstrate stored ratios change while behavior logs do not. Frozen reference outputs remain unchanged after encoder+decoder updates. Sampler restores modes on success/failure. All-correct/all-failed groups have truthful zero-variance counts; mixed rewards produce the intended updates. Explicit SFT replay changes parameters; forbidden teacher/held-out examples cannot reach either objective.

Reference: [DeepSeekMath / GRPO](https://arxiv.org/abs/2402.03300), inspected 2026-09-16. Its pretrained-model success is not evidence GRPO beats SFT here.

Record selection probabilities before the update and pass them to the update; without-replacement selection cannot use a naïve per-arm categorical probability as its inclusion probability. A simple cost-aware scheduler with explicit uniform exploration is preferable to retaining an incorrectly named EXP3 update.

Default budget example: four distinct active prompts, minimum two and maximum sixteen candidates each, total32, with 25% uniform task exploration. Allocate remaining candidates using recorded uncertainty/frontier evidence per execution cost, cap and deterministically redistribute. Test non-identical allocations on heterogeneous fixtures, exact sum/caps, and inability-to-fill outcomes. These defaults actually permit adaptivity unlike two prompts capped at16 under total32.

Make archive admission atomic: validate terms, source/codec round trip, independent execution and provenance before changing canonical or legacy views. Never fabricate extrapolation flags or costs. Archive verified programs independently of model context; retain `training_eligible`, token accounting, profile/evidence horizon and exclusion reason. Keep up to four non-dominated implementations per output identity with deterministic priority across source length, reference operation count/runtime tier and structural diversity. Equal output alone is not source deduplication; ambiguous 20-term prefixes retain independently valid longer-output alternatives. Unknown/long programs may be archived but cannot be truncated into replay. Repair CGI hardcoded512 through the shared eligibility service; CGI is SFT only in the strict track. Deduplicate training retrieval by source+semantics, retain output→multiple-program relationships.

Selected dormant replay must enter a real teacher-forced batch and increment used examples only after a successful optimizer step. Initial self-training uses a frozen per-round archive view and fixed replay fraction (25% recorded, rest generic data); checkpoint snapshots include replay cursor, archive root, scheduler observations and active reference. Test constant 8/16 competence over visits creates zero decay slope; all invalid admissions are atomic; longer valid source is retained but excluded from current context; replay gradients are nonzero on a toy task; resume reproduces the next selections and update.

## 4. Exact conditioning and generic structural splits

Targets: `src/oeis_learn/encoder/{tri_stream_encoder,magnitude_stream,modulo_stream,difference_stream,heads}.py`, `src/oeis_learn/data/{preprocessing,models,synthetic_generator}.py`; planned generic AST/pool modules from 007. Preserve existing floating features as optional streams but remove the claim they are exact.

Use authoritative signed integers encoded as sign plus32 little-endian magnitude bytes (negative zero forbidden), and exact rebased model-index encoding (never the private OEIS source offset), validity/missing masks and prefix length. Input encoding itself must round trip and distinguish adjacent large values before learned projection; no claim that a finite learned embedding stays mathematically injective. One efficient proposed term embedding flattens the32 byte embeddings with byte-position information and projects to model width; sign and index are separate channels. It preserves a complete discrete source representation without requiring 640 full-attention term-byte positions. Index representation must not be lossy float conversion. Signed256 minima work because magnitude2^255 fits32 bytes.

Compute differences/residues using host integers before embedding; derived differences can exceed256 bits, so expose exact wider-derived encoding or an explicit range mask rather than wrapping. Include modulus2/powers-of-two and bounded valuation semantics, including a distinct zero valuation tag. Every auxiliary head must have an active, specified measured objective or be absent from the optimizer/config; no dormant loss switches. Fixed20 is the primary user-confirmed protocol. Diagnostics at5/10/20 use separately frozen visible-prefix manifests; they are not permission to reveal more than20 values to the primary model. Encoder optional-stream ablation can reuse the bounded pilot if the streams materially dominate cost or convergence fails.

Generic generator samples typed expression/control constructors and constants, not named OEIS solution templates. Define a canonical structural signature by alpha-renaming locals, replacing literals with typed placeholders, preserving control/data dependencies and operator identities. Assign structural groups to train/dev/final before sampling parameter variants; also reserve explicit unseen operator-composition groups. Record both identity and harder structural-family scores. Never expose group/family/sequence IDs to the neural policy. Record signs, widths, constant/loop depth, runtime tier and output degeneracy; reject collapsed duplicate outputs only for sampling weight, retain distinct correct programs in the archive.

Accept exact boundary and neighboring-value round trips, finite features for zero/extremes, group-disjoint parameter variants and operator combinations, hidden/metadata invariance, and at least one successful optimizer update using each declared active feature path. Named-family diagnostics do not become routing rules or teachers.

## 5. Typed logical IR, search and self-training

Extend the planned `sandbox/wat_ast.py` into a typed logical program layer with canonical wide-value expressions, typed locals, conditionals, bounded loops, indexed input, explicit return, exact literals and typed constant slots. Keep parser/source AST distinct from normalized logical operations. Deterministic lowering emits WAT four-limb helpers; learned serialization can use one logical wide operation rather than exposing limb implementation scaffolding. Both direct WAT and logical serialization share final acceptance and exact output contract. This is a WAT-targeted representation change within007, not a LODA prototype. Version codec/checkpoints and preserve only legacy inspection compatibility.

Add bounded `evaluation/search.py` (planned), adapting `evaluation/synthesis.py` and `decoder/sampler.py`. Baseline is greedy plus stochastic generation. Implement alternative bounded beam/best-first and local typed repair in the same service; initial optional portfolio splits a total32-candidate budget16 stochastic/8 beam/8 repair and charges all generation, expansions, executions, solver calls and retries to a shared wall/token ledger. Freeze portfolio before evaluation. Retrieve only verified training archive programs; related held-out solutions never enter prompt/retrieval. Replay source reuse changes scientific interpretation, so model-only and model+search/retrieval results remain separately labeled. An enumerative/recurrence-solver baseline must be separate from the learned strict policy and charged identically; it must never silently become a teacher.

Canonical source dedup can avoid exact repeated work. Finite semantic fingerprints identify promising reuse, not proven equivalence; do not prune a distinct source solely because it matches on a short prefix. Partial execution pruning requires a typed complete expression or semantically terminal mismatch; arbitrary incomplete WAT is not executable evidence. Cache solved skeleton systems by structure/dependencies/indices/semantics and RHS separately. Repaired/grounded final candidates re-enter final-source validation and exact execution.

Self-training alternates frozen SFT rounds with bounded searches on training prefixes. Extra training-only indexed terms can independently verify admission, but dev/final hidden values remain physically unavailable to proposer/admission workers. Near-miss output lookup targets training partitions only. Version archive roots per round, retain diverse implementations, and reverify on any compiler/semantics change before reuse. Apply expanded canonical structure, parameter-bin and operator-composition exclusions to every admission, replay, retrieval and mined macro; a training-prefix origin cannot bypass synthetic holdouts. Archive excluded valid candidates as non-training evidence only. Learned abstraction extraction is a bounded, conditional in007 capability: mine frequent typed subtrees only from permitted archive programs, require semantics-preserving expansion and net description-length benefit, then admit a versioned macro dictionary. It is not hand importing OEIS algorithms. Learned value/repair policies require a measured baseline search failure and a manifest gate; MCTS is not mandatory absent that evidence. Record an evidence-backed `baseline_retained` or `inconclusive` outcome rather than silently postponing to another spec.

Acceptance: grammar/type-valid round trips for every operator and boundary; lowered/reference agreement; deterministic expansion caps; candidates rejected by one worker cannot contaminate another; negative provenance/retrieval tests; beam/repair budgets never inflate reported any@K; self-training admits new training examples with honest evidence and cannot read final truth. See [Alien Coding](https://arxiv.org/abs/2301.11479) and [grammar-aware synthesis](https://arxiv.org/abs/1805.04276), inspected2026-09-16; neither transfers a measured speedup or success threshold to this project.

## 6. KV cache and hardware engineering (include)

Targets: `src/oeis_learn/decoder/{wat_decoder,transformer_decoder,sampler,grammar_masker,environment_tracker}.py`. Introduce `prefill(prompt_tokens,memory,identity)` and `decode_step(token,state)` with per-layer self-attention K/V and precomputed encoder cross-attention projections. Use bounded preallocated cache buffers, per-row lengths and active masks; invalidate on weight, conditioning, dtype/device, positional profile or grammar changes. Cross-attention axes are encoder term indices, self-attention axes are program-token positions. Teacher-forced training retains the uncached causal path. Restore module modes. Beam row reordering must reorder all K/V, masks, grammar states and source identity together. Multi-prompt batching and length buckets use unique per-candidate RNG streams so scheduler completion order does not alter outputs.

Replace fixed-width vocabulary bit assumptions with sized boolean/word-array masks and precomputed static grammar transitions plus dynamic stack/local/scope checks. Vectorize batch logits masks without claiming dynamic grammar is stateless. Avoid per-token `.item()` synchronization when possible, recording residual CPU/GPU synchronization rather than inventing speedup claims. SDPA is an optional qualified backend with a clear eager fallback; explicit dropout_p=0 in inference and correct cache attention masks are essential.

Acceptance compares cached/full-prefix per-step logits in FP32 at lengths1,2,513,1024, padded multi-prompt batches, empty/finished rows and beam reorder. Fix numeric tolerance before run (atol=1e-5/rtol=1e-4), require identical selected actions when margins exceed tolerance, test stale identity rejection and cache capacity. Measure warmed generation and end-to-end candidates/hour, with memory peak and cache footprint; don't claim linear total attention complexity (cached self-attention still quadratic over generated length). Timing speed is measured; semantic equivalence is a hard gate.

One hardware profile session, not separate training arms: compare CPU workers 4/8 only; test FP32 correctness then FP16+GradScaler finite/equivalent behavior; BF16 only if supported. Cap threadpools, queues and total container memory. Record thermal steady-state end-to-end throughput for at least10minutes after warmup, not only a GEMM result. Choose a compatible measured configuration and freeze it. Actual GPU unavailable remains a failed readiness result, not silent CPU success.

Reference: [PyTorch SDPA documentation](https://docs.pytorch.org/docs/stable/generated/torch.nn.functional.scaled_dot_product_attention.html), opened2026-09-16; exact implementation must be checked against the pinned PyTorch version.

## 7. Streaming, arrays and primitive coverage

Targets: `src/oeis_learn/sandbox/{runner,fallback_runner,lowering,preamble}.py`, `sandbox/preamble.wat`, planned reference/pipeline/workers. Keep existing pure `compute(n)` profile. Add separately versioned stateful `init(start_index)` + `next()->four i64 limbs`, one instance per candidate stream, explicit reset on every new candidate/prompt/horizon. `next` emits the sequence value at the current index before increment, according to an exact documented origin. The reference initializes the same state independently. `next_block(count)` is a bounded adapter for1<=count<=120 repeated next calls, returning committed values and an explicit failure position; it does not waive per-next limits or make partially failed blocks atomic. A random-access wrapper reinitializes and advances; it must not pretend to offer the same performance contract as native random access. Whole-stream aggregate fuel/deadline and per-next limits both apply. Snapshot pre-next state or deterministically reset and replay before retrying after exhaustion/trap; all replay work is charged. Commit output/index/state atomically only on successful next. Checkpoints contain only committed transitions; no partially mutated stream is resumed.

Add bounded logical signed256 arrays, default maximum1024elements/candidate and checked nonnegative indexing; no growable/unbounded memory. Use one64-KiB linear-memory page (maximum one page, memory.grow forbidden), with32KiB for logical cells and the remaining area reserved for checked helper/output state. Arbitrary guest pointer arithmetic is outside this profile; typed array helpers enforce element bounds. Lower to linear memory with overflow-safe byte-offset arithmetic, bounds checks, zero initialization and no import escape. Preserve typed4-limb element semantics and alias/reset rules. Add full signed256 add/sub/mul, div/rem (truncate toward zero, remainder dividend sign), comparisons, bitwise operators, checked casts and shifts with explicit shift-range behavior; reject division by zero and min/-1 overflow. Negative shift counts and counts>=256 are rejected in logical IR instead of inheriting masked native shifts accidentally. Arithmetic right shift and logical shift must be distinct opcodes. Logical left shift is checked mathematical multiplication by2^k; overflow is numeric_limit. A distinct logical-right-shift opcode operates on the256-bit pattern then reinterprets the result as signed. Arithmetic right shift sign-extends. Native i32/i64 shifts retain WASM masking semantics. GCD remains expressible library code; any fixed primitive or mined macro gets explicit provenance/prior declaration.

Calibrate fuel tiers from actual current lowering, e.g.three monotone per-call search tiers with bounded retries ending at the profile's1m cap and50m aggregate, not hardcoded claims that50k suffices. Independent final verification uses the frozen highest tier. Resource exhaustion stays inconclusive, and consumed attempts/resources remain charged. Record operation count, per-call max, total fuel, p50/p95 and counts>=75% of limit; avoid one warning per term. Checked/unchecked overhead may be measured on the same oracle-proven in-range fixtures, with separate trace instrumentation and timing; never allow unchecked execution to silently certify checked semantics.

Acceptance: streaming Fibonacci-like generic recurrence agrees with pure/reference outputs and total logical work scales linearly for N=20/50/100/120; random-access wrapper parity; state reset independent of prior executions; arraybound/alias/zeroing tests; independent operator boundary/property suite; classified resource tiers preserve denominator and cannot refund work. These features increase expressiveness but do not guarantee broad coverage from20terms.
