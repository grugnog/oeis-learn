# Design and task review checklist

**Feature**: [spec.md](../spec.md) | **Date**: 2026-09-16

- [x] Research states decisions, rationale, alternatives and pinned source evidence.
- [x] Plan identifies current files separately from planned modules and runtime claims.
- [x] Numerical profile defines logical signed checks and native bit-vector behavior.
- [x] Independent reference shares no production numerical helpers/lowering.
- [x] Full-range literals/local IDs have lossless serialization and a frozen codec.
- [x] Source completeness, grouping algorithm, representatives, split seed/counts and denominator are explicit.
- [x] Data views/process mounts and public-only seed projection prevent accidental hidden influence.
- [x] Final decision lock and per-target seal precede any hidden scoring; retry behavior is defined.
- [x] Program/admission/evidence identities form an acyclic graph.
- [x] External checkpoint manifest hashes final immutable blob bytes; publication/recovery order is specified.
- [x] Crash gaps cannot refund budget; estimated and measured durations are distinct.
- [x] Standalone preflight has its own module/config before later CLI/profile tasks exist.
- [x] Named teachers, imported programs, legacy replay and false proof promotion are unreachable in the strict path.
- [x] Tasks include exact paths, story labels, real dependencies, independent test criteria and safe parallel opportunities.
- [x] All source/runtime implementation tasks remain unchecked.

This review precedes the formal read-only Spec Kit analysis. Validation results and remaining implementation gates are recorded in [validation/report.md](../validation/report.md).
