# Data model and state transitions

All new formats are proposed under the `round029-…/v1` namespace. Store them with the existing canonical serializers and content references. A stored reference binds format, digest, byte length and allowed owner. An operational retry receives a new attempt ID and retains the logical operation ID. Historical objects keep their original version and verifying reader. [Existing record primitives](../../src/oeis_learn/generalization/progressive/contracts.py) · [Spec 016](spec.md)

## Registration and scientific inputs

| Record | Required content and relationships | Validation and visibility |
| --- | --- | --- |
| Study registration | Study/parent identities, source and image revisions, scientific profile, frozen factors, seed streams, panels, possible looks and claims, directions, tie rules, clock convention, approved decision branches and authority references | Seal before the first comparative score. A child references a closed or resumable parent. Independent confirmation also commits the chosen candidate and comparator before replication scores. Publish commitments. |
| Authority and guard | Physical workspace, stage, registration, allowed operations, resource units, total and held-back allowance, current debit/reservation, owner, production basis, headroom, exhaustion action and rehearsal ID | Unique grant and ownership domain. A retry spends the original remaining allowance. Preflight can report an unfunded action. A confirmation grant has a separate purpose. |
| Family component and reservation | Private record/source revision, exact terms as integer text, original indices, behavior and shifted-window digests, structure/composition links, family/stratum, calibration band, permitted role and exposure history | Components cannot cross protected roles. Parameter variants obey their declared exception. Keep all 028 reservations. Validate the full roster before a score. Externally expose only opaque family/component tokens and counts. |
| Seed, recipe and stream | IDs 00–06, positive-stream and composition-law identities, training and initialization seed provenance, batch, decay, objective and auxiliary-weight identity, order, exclusions and verified draw IDs | A new study ID may reference the donor’s actual seed/stream. The ordinary-stream receipt is shared by 00/02/04/05/06 and the broad stream by 01/03 within seed. The new confirmation pair has independent training lineage. |
| Training pair or guide example | True row, actual decoded target, donor-visible projection, legal abstraction/parameter scope, verified counterexample or replayed impossibility evidence, exclusion class, weight and eligible training-family identity. Guide traces bind typed states and a set of verified next actions | Restrict witness/source, donor values, groundings and traces to private training/calibration roles. Matching loss reads eligible row/prefix/label projections. Live roles receive the approved visible inputs only. Ambiguous labels contribute zero auxiliary weight. |
| Donor compatibility | Donor registration/reader, weights digest, full-state cut, stream/cursor, source/runtime, exposure and historic ledger, ordered prompts, inference key, choice key, scorer/truth key, availability and reason per layer | Distinguish receipt reuse, rescore, fresh inference, full continuation and isolated control rerun. Equality at a lower layer permits only the operations that layer supports. |

## Execution and scientific evidence

| Record | Key and stored quantities | Validation and visibility |
| --- | --- | --- |
| Logical operation and physical attempt | Study, stage, recipe or search method, seed, look, panel, profile, input mode, role, case/shard ordinal and attempt. Store a parent operation and a unique physical attempt/lease | Key explicit fields. Distinguish the one-attempt and eight-attempt calls at 4M. Retry reconciles unfinished ordinals and debits. |
| Full learning cut | Weights, optimizer/scheduler, all RNG state, sampler and ordered-row cursor, useful positive tokens, charged tokens including discarded/repeated, whole-update count, since-parent and cumulative ledger offsets, checkpoint/profile IDs | Commit only at a complete optimizer update. Independently replay positive-row lengths to verify the cursor and useful count at each batch size. Retain overshoot. A child adds exposure to its authenticated parent. An evaluation-only weight file carries no continuation authority. |
| Search request and sealed result | Recipient and model/guide input identities, explicit profile and seed/tie policy. Attempt ordinal, partial expansion counters, decoded structure, fit/admission/timestamps, selected final-source identity or empty disposition, seal time, diagnostic-bank reference and closure status | The selector can use only visible data. Ground and admit on recipient values. All live arms seal before private scoring or bank inspection. A missing effective donor marks only its shuffle contrast unavailable. |
| Case observation | Roster family/stratum, method/seed/look/profile, choice receipt, scorer/reference and truth commitment, exact solve / measured miss / unresolved, scientific completion, search closure, original and remaining allowance, cost refs | One live choice per case and method. A verified solve may have incomplete search. A completed empty portfolio is a measured miss. Abandoned work can remain unresolved. Privileged known-structure success and best-in-bank status have separate fields. |
| Clock and spend | Physical resource owner, host/boot ID, monotonic interval, reservation, paid/unfinished/unused work, unique shared receipt and billing rule. Track end-to-end wall boundaries, CPU work, lease, sampled device coverage and phase | Separate verified time from conservative charges for unknown termination. Union compatible half-open intervals, keep unknowns visible, retain every failed debit, and prevent double attribution of shared work. |
| Decision and publication | Input commitments, eligible actions, estimates and remaining reserve, route/precedence and why, comparison/retention/support/uncertainty, scientific verdict, marginal cost, successor or stop, private replay, independent reader and public archive IDs | Only a predeclared and funded branch can dispatch. Recompute from the frozen denominator and commitments. A sealed assessment role is outside this release. |

## Durable transitions

| State or boundary | Legal next operation | Recovery invariant |
| --- | --- | --- |
| Preflight inventory | Bind eligible inputs and priced scope, or report the specific shortfall | A metadata read acquires no device. Missing private evidence restricts its dependent comparison. |
| Prepared → frozen → accepted | Retain each authenticated freeze choice, publish the frozen graph, qualify the exact candidate role path and accept the bound campaign | Recover the same validated choice or staged publication. Candidate/worker mismatch needs compatible evidence for affected work. |
| Authorized → reserved → running | Acquire physical ownership and register a debit before issuing a learner update or portfolio | One session owner and one GPU lease. Reconcile outstanding work after failure before any dispatch. |
| Output staged → independently checked → committed | Install content-addressed output, settle actual charges once, commit the transition referring to both | Recover output/charge/boundary gaps idempotently. A discarded update keeps its debit. A pending journal commit can reuse an installed report. |
| Look verified → decision recorded | Continue the same trial, follow a funded diagnostic branch, register/activate an independently funded repeat, or retain D | Historical trial state stays intact. A development observation can change the next spending action without becoming formal optimizer feedback. |
| Terminal → privately verified → published → archive verified | Re-export the identical committed report or inspect status | Public reader checks the separately retained pre-score commitment. Mechanical completion and the scientific verdict are independent fields. |

## Public sufficient statistics

For each opaque linked family/stratum, emit the frozen size and a histogram of **joint outcome patterns on the same cases** across the registered arms, looks and seeds used in each contrast. A pattern contains status and completion separately, a count, and equality classes for observations that refer to the same sealed outcome. Retain cross-stratum group links and known overlap for D and the common zero look. Supply the ordering of coordinates, cost/clock summaries, denominator, exposure and as-of key. Public data must support both factorial interactions, gains/losses and conservative bounds without reconstructing private prompts. Validate the encoding against a private row-level calculation, including singleton families. Use run-scoped opaque labels with no OEIS IDs, source hashes usable as case IDs, terms, weights or candidate bytes.

The public archive also carries the freeze and grant commitments, guard bases, actual costs/unknown intervals, joint resampling seed and multiplicity, route evidence and independently computed verdict. A private receipt binds those public cells to the original scorer choices. This allows an archive-only reader to verify the comparisons while keeping exact program replay with the private scorer.
